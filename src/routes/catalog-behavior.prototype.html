Candidate contract in this demo

  1. Discovery uses /templates. Default values are absent from the URL.
  2. Query order is q, layout, ats, tone, density, photo, then sort. Multi-select filters repeat the key and follow the controlled-value order.
  3. Detail uses /templates/:templateId. It accepts mode, lang, and file. Default preview, English, and the first source file are absent from the URL.
  4. The browser Back action restores the exact discovery URL. Detail links do not copy discovery state into their query. Discovery controls and detail controls replace the current history entry. Opening a template creates a new entry.
  5. Code mode copies only the selected file. Copy status appears beside that file and clears when the selected file changes.
  6. The named shadcn command is primary. The direct HTTPS command is always visible as a fallback. CV UI does not try to detect a CLI failure.
  7. A failed Clipboard API call keeps the command selected and shows manual keyboard-copy instructions. It never reports success before the promise resolves. Copy status has no timer. It clears when the command, source file, or detail mode changes.
  8. Wide screens keep the install panel sticky. Narrow screens show a fixed "Install" action that opens a focus-trapped sheet. Close, Escape, and backdrop click dismiss it and return focus to Install. Copy actions keep it open. Panel state is not part of the URL.
  9. Unknown query keys are ignored and removed when CV UI next changes the URL. Unknown values fall back to defaults. An unknown Template ID shows the normal not-found page.
