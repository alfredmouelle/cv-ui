# cv-ui

`cv-ui` is an open-source catalog and live showcase for CV and resume templates. It will provide copy-pasteable React and Tailwind templates and shadcn registry installation for human developers and AI coding agents.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. See `docs/agents/domain.md`.
